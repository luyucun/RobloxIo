# 核心玩法循环

> 本文概括 IO项目（对剑）的玩家体验与核心循环。具体规则以 `需求文档.md` 与 `框架设计.md` 为准；本文与代码冲突时以代码为准，并按 README 流程先同步文档。

## 一句话概括

玩家从准备区进入战斗区，以环绕武器击杀小怪和 Boss 获得经验升级，升级增强血量并重建更强的武器组，与其他玩家用环绕武器对拼互相淘汰，死亡后通过免费半级复活或付费保级复活重回战场，长期追求等级、击杀数与外观收集。

## 目标玩家与体验承诺

- 目标用户：偏好轻中度 IO 对战、升级成长与外观收集的 Roblox 玩家。
- 单次游玩时长：单局 5-15 分钟；等级与外观成长跨局延续。
- 最重要的手感/情绪：经验块吸附升级、武器组变强变多的即时正反馈，武器对拼淘汰他人的爽快。
- 不能牺牲的体验：等级、伤害、击杀、武器胜负必须可信（服务端真值）；武器环绕与经验飞行的表现必须顺滑。

## 核心循环

```text
出生在 SpawnLocation → 走到 Map2.Portals.Portal 触碰弹出 JoinGame → 点击 Join 进入 workspace.Battle
→ Lv1 / 100 血 / 1 把 T1 环绕武器 → 击杀本地私有小怪或服务端 Boss → 经验块飞向玩家、服务端立即结算经验
→ 升级（血量+10/级、武器组重建、最多 10 把）→ 与其他玩家/Bot 武器对拼（高 CombatRank 胜、同级双败）
→ 死亡弹出 Defeated 面板 → 免费半级复活 / 付费保级 / 复仇 / 回大厅 → 继续战斗
→ 排行榜（单服等级/击杀 + 全局游玩时长/总击杀）长期沉淀
```

| 阶段 | 玩家行为 | 即时反馈 | 服务器结果 | 长期价值 |
|---|---|---|---|---|
| 入场 | 触碰 Portal，点 Join | 弹窗确认、模糊背景、传送 | 校验 Portal 资格（8 秒窗口）后传送进 Battle，首次入场发 60 秒新手护盾 | 进入对战 |
| 打怪 | 走近小怪，环绕武器自动命中 | 伤害数字、怪物死亡、经验块飞向玩家 | 客户端 token 化上报击杀，服务端按 MonsterCatalog 结算经验与重生积分 | 经验来源 |
| 升级 | 持续击杀 | 升级特效、血量上限提升、武器组变多变强 | 服务端结算等级/血量/武器期望状态并同步 | 核心成长 |
| 对战 | 靠近其他玩家 | 武器对撞弹飞、命中本体掉血击退 | 服务端 Aura 盒体判定，比 CombatRank 定胜负，伤害/死亡服务端结算 | 淘汰他人、击杀数 |
| 死亡 | 被击杀 | Defeated 面板展示击杀者与复活选项 | 服务端判定死亡，清空局内状态 | 惩罚与付费点 |
| 复活 | 选免费/付费/复仇/回大厅 | 复活动效、重回战场 | 免费回大厅=半级复活；付费保级；复仇购买后复活并反杀目标 | 继续循环 |
| Boss/事件 | 参与 Boss 击杀、特殊事件 | Boss 反馈、事件场景与图标 | 服务端生成 Boss、事件效果（移速/经验/血量/钻石/护盾）服务端生效 | 中期目标与变化 |
| 长期 | 任务/宝箱/转盘/皮肤/尾迹/称号 | 各系统面板与动效 | 服务端权威发奖与存档（IO_PlayerRebirth_v1） | 留存与付费 |

## 已确定的关键规则（摘要）

- 单服最多 10 名真实玩家；单 Place，无匹配队列。
- 等级上限 Lv610；血量 `100 + (Level-1)*10`；经验为分段固定曲线（详见 GameConfig.EXPERIENCE）。
- 武器 T1-T40 可见（Lv401-610 在 T40 外观下隐藏 CombatRank 41-61 继续成长）；每档最多 10 把，跨档逐把替换。
- 武器对拼：高隐藏 CombatRank 胜、同级双败、被拼掉的武器弹飞移除；只剩 1 把时该武器不会被移除（规格：反转环绕方向，见 BUG 清单）。
- 普通小怪为客户端私有（每人上限 350，只对本人可见），通过受限 RemoteEvent 上报、服务端校验结算；Boss 为服务端权威。
- 死亡不自动复活；免费复活与回大厅均为 `max(1, floor(死亡前等级/2))`，经验和局内击杀不恢复。
- Defeated 付费 Revive 按死亡前等级、经验和局内击杀数复活；Revenge 复活并尝试击杀原击杀者。
- 特殊事件每 10 分钟按权重触发（排除最近 2 次），效果全部服务端生效。
- Studio 环境：不读写正式 DataStore；GM 命令仅 Studio 可用，线上拒绝。

## 长期目标

等级成长（Lv610）→ 武器外观全收集（皮肤/尾迹）→ 局外属性上限养成 → 全局排行榜（时长/击杀）→ 称号与装扮展示。
